# AI 熱度榜雷達：每日 TOP 5 榜單貼文＋靜態網站同步

> 每天早上固定時間，掃多個來源產出一份 TOP 5 熱度榜單：貼文直接發，靜態網站同步更新，網站跑馬燈必須跟當天榜單同源同天。

- **適合**：經營內容品牌、每天需要一則「今天 AI 圈在紅什麼」固定欄目的人
- **驗證標記**：✅ 真機跑通
- **成本量級**：低

## 場景

AI 新聞每天幾十條，讀者沒時間追。你每天早上給他一份「TOP 5＋一句人話點評」，連續發 30 天，這個欄目就變成你的招牌。但榜單要可信：來源要多、數字要有出處、網站上的榜單必須跟貼文是同一份。

## 輸入

- 監控清單：社群監控帳號（增刪由你拍板，約 10–20 個）、GitHub trending、技術媒體快訊、開發者論壇熱門、搜尋引擎地區熱搜
- 發布渠道：`<你的粉專>`（圖文直發）
- 靜態網站：榜單站（首頁跑馬燈＋每日歸檔頁）
- 每日 JSON 存檔：`<共用資料夾>/data/heat/YYYY-MM-DD.json`（唯一真相，網站從這裡 build）

## 步驟

1. **掃來源（早上）**：排程觸發，按監控清單抓昨晚到今早的候選：社群貼文（看轉發與討論熱度）、GitHub trending 新上榜工具、技術媒體頭條、論壇熱門帖、地區熱搜進榜的 AI 話題。
2. **收斂 TOP 5**：去重（同一事件只留一條）、排序，寫「熱度指數」＋「一人公司視角」點評（這條對獨立開發者／一人公司意味著什麼，一句話）。
3. **發貼文**：圖文直接發布。內文結構：標題行（日期＋AI 熱度榜）→ TOP 5（每條：標題＋熱度指數＋一句點評）→ 結尾標籤。**外連不放內文**。
4. **首條留言**：固定文案＋完整版連結（「想看完整榜單？TOP 10 完整版＋每條詳細點評在這裡」＋榜單站連結），由人手動貼在首條留言。
5. **同步網站**：把當日 JSON 寫入存檔，用 build 腳本更新靜態站。**鐵律：首頁跑馬燈必須跟當天榜單同源同天**——網站更新排程要在貼文發出後跑，跑完檢查跑馬燈內容＝當天 TOP 5。
6. **歸檔**：每日 JSON 永久保留；網站首頁只顯示最近 7 天，更早的自動轉入歸檔頁（每日一個永久網址，可被搜尋收錄、累積長尾流量）。

## Prompt 範例

榜單收斂（餵給 agent 的候選清單）：

```text
你是 <你的品牌> 的 AI 熱度榜編輯。以下是今早掃到的候選（附來源連結與熱度線索）：
{{候選清單}}

請輸出今日 TOP 5：
1. 去重：同一事件只留一條，選來源最可靠、資訊最完整的那條
2. 每條格式：標題（≤20 字）｜熱度指數（1–5 星，依跨來源出現次數與討論量）｜一人公司視角點評（一句話：對獨立開發者意味著什麼）
3. 排序：綜合熱度由高到低
4. 規則：沒有可靠來源的不寫；傳聞類標註「傳聞」；數字（星數、下載量）用抓取當下的值，不要抄昨天的
5. 最後附一行：今日關鍵詞（3–5 個，給歸檔頁用）

輸出繁體中文，語氣生動但專業，不誇大。
```

## 坑

- **跑馬燈與榜單不同天**：網站更新排程和發文排程是兩條線，時區或失敗重試會讓它們錯開。鐵律寫進檢查清單：每天人工瞄一眼跑馬燈＝當天榜單。
- **首頁越長越慢**：榜單每天 +1，全列在首頁會越捲越長。首頁只留最近 7 天，舊榜單進歸檔頁（還有永久網址賺長尾流量）。
- **數字抄錯天**：星數、下載量每天都在變，榜單裡的數字必須用「收斂當下」抓到的值，不要複製貼上昨天的。
- **外連放內文**：平台會降觸及含外部連結的貼文。完整版連結只放首條留言，由人手動貼。
- **監控清單不迭代**：每週看一次「哪個來源連續一週零命中」，該換就換；清單是資產，不是祖產。
- **單一來源的熱度榜**：只盯社群話語的做法見改編配方 `x-radar.md`；這篇是「多來源收斂成榜單」的完整管線。
