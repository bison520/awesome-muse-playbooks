# 每日賺錢靈感管線：挖掘→證據分級→去個人化→存檔成庫

> 每天產出一則「可執行的商機」貼文：多來源挖掘、證據分級誠實標註、去個人化改寫、長期存檔——跑滿一個月就是一座商機資料庫。

- **適合**：經營一人公司／副業內容，每天需要一則高價值原創貼文的人
- **驗證標記**：✅ 真機跑通
- **成本量級**：免費

## 場景

「賺錢靈感」類內容最怕兩件事：寫成心靈雞湯（不可執行）、證據亂吹（被拆穿一次信用歸零）。這條管線用三個機制解決：每天只寫第 1 名（逼自己排序）、證據分級（已驗證 vs 推論要寫清楚）、去個人化（讀者拿走就能用，不用認識你）。

## 輸入

- 靈感來源：支付數據反查（從「誰在付費」反推賽道）、社群討論、工具榜單、讀者投稿（多來源，不要只靠一個）
- 證據分級標準：A＝已驗證收入（有公開數據或可查證的付費事實）、B＝強推論（多個間接證據指向同一結論）、C＝假說（邏輯自洽但缺證據）
- 篩選鐵律：需要特定身分證／銀行帳戶／平台實名才能變現的項目，一律跳過不寫
- 固定結尾：每則貼文底部的「使用說明＋AI 提示詞」範本（原文沿用、不改寫）

## 步驟

1. **挖掘**：每天從多來源抓 5–10 個候選，記下每個的來源連結與初步證據。
2. **證據分級**：每個候選標 A／B／C。B 和 C 必須在成文明確寫出「這是推論」或「這是假說」——誠實聲明是這類內容唯一的護城河。
3. **只寫第 1 名**：按「可執行性×證據等級×時機」排序，每天只寫第 1 名，800–1000 字完整拆解：
- 機會描述（這是什麼）
- 為什麼是現在（時機窗口）
- 第一步怎麼做（拆成具體步驟，讀者今晚就能動手）
- 難度與投入評估（時間／錢／技能，誠實寫）
- 證據等級聲明（A／B／C＋一句話說明）
4. **去個人化改寫**：刪掉所有稱呼、事業、人稱指涉，改第三人稱；個人偏好一律不寫入。目標：陌生人讀完覺得「這是寫給我的」，而不是「這是某人的日記」。
5. **固定結尾**：貼文底部附「使用說明＋AI 提示詞」（讓讀者把這則靈感丟給 AI 幫他規劃），提示詞原文沿用、不要改寫——一致性本身就是品牌。
6. **雙軌存檔**：原始版（內部）＋大眾版（發布）都存檔，按日期歸檔。跑滿一個月後，這批存檔就是「商機資料庫」的地基（可做訂閱或收費專欄）。

## Prompt 範例

去個人化改寫：

```text
把以下賺錢靈感草稿改寫成「大眾版」貼文（繁體中文）：

{{原始草稿}}

規則：
1. 刪除所有稱呼、個人事業、人稱指涉（我／我們／我的讀者），改第三人稱或直接對讀者說話
2. 保留：機會描述、為什麼是現在、第一步的具體步驟、難度與投入評估、證據等級聲明
3. 個人偏好、個人經歷一律不寫入（除非它是證據的一部分）
4. 結構：鉤子第一句 → 機會 → 為什麼是現在 → 第一步（拆步驟）→ 難度投入 → 證據聲明 → 固定結尾
5. 800–1000 字；語氣生動口語；不承諾收益、不寫「保證賺錢」類字眼
6. 最後原樣附上：{{固定結尾範本}}（一字不改）

輸出可直接發布的貼文全文。
```

## 坑

- **證據亂吹**：B／C 級寫得像 A 級，被拆穿一次，整個欄目信用歸零。證據聲明不是免責聲明，是內容的一部分。
- **需要特定身分才能做的項目**：變現需要特定證件／銀行帳戶／平台實名的，直接跳過——讀者做不到的靈感只是噪音。
- **寫成雞湯**：「保持熱情」「相信自己」這種句子出現，就代表第一步沒拆夠細。檢驗標準：讀者今晚能不能動手做第一步。
- **個人化殘留**：「我昨天跟朋友聊到」這類句子沒清乾淨，大眾版就破功。改寫完專門掃一遍人稱。
- **固定結尾被改寫**：提示詞範本每次微調一點，三個月後就面目全非。原文沿用，一字不改。
- **只存發布版**：原始版也要存。未來做資料庫時，原始版的來源連結與分級記錄才是值錢的部分。
